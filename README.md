# Swathy & Rahul — Baby Shower Invitation

Static HTML, CSS and JavaScript version of the six-slide invitation. Original slide artwork and background music are included without image resizing or recompression.

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of your repository's `main` branch.
2. In GitHub, open **Settings → Pages** and set the build/deployment source to **GitHub Actions**.
3. The included workflow deploys the site automatically after a push to `main`.

Expected URL: `https://rahul96761380.github.io/Swathy_Rahul_Invite/`

Music starts only when a visitor presses **Music** (browser autoplay restrictions). Slides auto-advance every 8 seconds; visitors can pause, navigate, tap dots, or swipe.
